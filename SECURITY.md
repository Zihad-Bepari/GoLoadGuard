# Security Policy

## Supported Versions

Only the latest release of GoLoadGuard is officially supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability or a critical concurrency bug that could lead to resource exhaustion, deadlock, or denial-of-service, please report it privately:

1. **Do not open a public issue.**
2. Send an email with reproduction steps and proof-of-concept to the repository maintainers.
3. We will acknowledge receipt within 48 hours and work with you on a patch and responsible disclosure timeline.
